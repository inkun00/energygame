# 에코 탐험대 캐릭터 모델

이 폴더의 GLB 9개는 보드와 캐릭터가 등장하는 미니게임 8종이 함께 사용한다. 캐릭터마다 메시 한 개, 스킨 한 개, 내장 1024×1024 색상 텍스처를 사용한다. 통학 버스에 등장하는 두 학생은 [학생 모델 제작 기록](../school_pupils/SOURCES.md)에 별도로 정리했다.

## 형태

캐릭터 원화의 정면·측면·후면을 공식 TripoSR로 복원한 고해상도 표면과 기존 Blender 관절 원본을 바탕으로 이번 게임용 메시를 만들었다. Blender 4.5.15에서 얼굴과 굴곡이 큰 외곽선에 정점을 추가하고, 원본과 법선 방향이 일치하는 부분을 고해상도 표면에 다시 밀착시켰다. 발바닥 위치와 캡틴 에코의 두 손·망토처럼 수작업으로 분리한 경계를 보존했다. 원래 UV와 관절 가중치를 보간하고 각 정점의 영향 뼈는 최대 4개로 정규화했다.

## 움직임

보드는 `idle`, `walk`, `jump`를 사용한다. 미니게임용 `run`에는 더 긴 보폭, 상체의 전방 기울기, 발목 목표에 맞춘 무릎 굽힘을 적용했다. 포포는 지느러미를 젓는다. 각 리그는 보드 보폭과 달리기 보폭을 별도로 기록하며 게임은 이동 거리로 동작의 진행 시점을 정한다. `operate`는 정지한 발을 유지하며 두 팔로 계기를 움직이는 동작이다. 게임 좌표에서 앞은 로컬 +Z, 바닥은 Y=0이다.
