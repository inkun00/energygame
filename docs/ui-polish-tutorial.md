# UI 완성도 개선과 행동형 튜토리얼

## 적용 내용

- 보드: 현재 캐릭터 확대·이름표·발밑 링, 실제 이동 경로와 도착 칸 표시, 전경 소품 가림 제거. 100칸 및 이동 규칙 유지.
- 정보 배치: 플레이어 이름·에너지·SP 가독성 확대, 중복 턴 안내 제거, 주사위와 특수기술 정렬. 1024×600 기준으로 도감·시장·건설·결과 영역 확인.
- 로비: 9명 얼굴 선택창과 기술 이름, 키보드 포커스 순환. 도입 이야기는 명시적인 다음/건너뛰기로 진행.
- 건설: 시설 선택 후 지도 클릭 또는 방향키/Enter 배치, 기존 드래그 유지. 부적절한 지형 클릭은 재료를 소모하지 않고 선택을 유지. Esc로 선택 취소.
- 퀴즈: 해설 원리를 먼저 표시하고 정답·보상 상세를 뒤에 배치. 답변 즉시 채점 및 온라인 흐름 유지.
- 지도: 기존 지형 구성을 유지한 저용량 모형 스타일 배경과 건설 위치 정렬. [생성 방식과 프롬프트](../assets/maps/DIORAMA_SOURCE.md).
- 미니게임: 태양·패널 비교 대상을 가까운 한 줄로 제한, 풍향·터빈 정렬 비교, 공급 부족에 따른 도시 조명, 대기/사용중 기기 상태, 물→터빈→발전기→도시 흐름, 운반 물체 연결, 배터리 전달 흐름, 버스 정차 표시와 분산 하차, 창문 차단 전후 전력 비교.
- 미니게임 선택: 실제 장면 썸네일 확대, 행동 한 줄과 키 안내, 작은 화면 2열 및 키보드 스크롤. 썸네일은 새 장면으로 다시 캡처.

### 추가 마감 수정

- 캐릭터: 태양광·대기전력·수력에서 확대된 캐릭터의 그림자를 실제 바닥/발판 높이에 맞춘다.
- 풍력: 돌풍 경고를 회전축을 가리지 않는 위치로 옮기고 발전 출력·정지·바람 전환 시간을 표시한다. 배경 터빈도 위험 돌풍에서 정지한다.
- 대기전력: 기존 오픈소스 벽의 실제 크기에 맞춰 틈을 없애고 걷는 위치까지 바닥을 확장한다. 플러그는 옆으로 짧게 뽑히도록 수정한다.
- 스마트그리드: 측정 전 평균값을 0으로 오해하지 않도록 시작 후 측정된다고 안내한다.
- 버스: 45명 전원이 3명씩 순차 하차한다. 하차용 모델은 최대 9개를 재사용하며 전체 입장은 3.85초 안에 마친다. 경쟁 종료 뒤 연출이 점수나 시간을 바꾸지 않는다.
- 냉방: 창문의 더운 공기와 냉방 공기를 부드러운 주황·파랑 흐름으로 표현한다. 창문·기기 원본 에셋은 유지한다.
- 공통 효과: 화면을 덮는 성공/충돌/범람 효과를 약하게 통일하고, 가져온 재질의 중복 색변형과 일회성 재질의 캐시 누적을 막는다.
- 엔딩: 같은 마을의 0→50→100 회복 그림과 선택한 네 캐릭터의 실제 퀴즈·재료·완공 기여를 표시한다. 읽기 시간은 6·6·9초이며 직접 넘길 수도 있다.
- 성능: 가려진 보드의 렌더와 시각 애니메이션을 중지하고, 정적 타일 100개의 불필요한 프레임 콜백을 제거한다. [측정 조건·효과·한계](render-performance-benchmark.md).

## 튜토리얼

로비의 **튜토리얼** 또는 `?tutorial=1`로 시작한다. 선택한 히어로와 AI 3명이 있는 별도 연습 세션이다.

1. 실제 주사위를 굴려 1칸 이동하고 재료를 획득한다. 첫 이동만 학습 순서를 위해 1로 고정된다.
2. 실제 건설 도감에서 목표 시설을 고른다.
3. 실제 퀴즈에 답하고 해설을 읽는다. 정답 여부와 관계없이 원리를 확인하고 다음으로 진행한다.
4. 스마트그리드 미니게임을 30초 진행하고 4명의 점수·보너스를 확인한다.
5. 선택한 시설에 필요한 연습 재료로 실제 건설 칸에 배치한다.

주사위 자동 진행·탐험 제한시간·퀴즈 읽기 제한은 연습에서 정지한다. 미니게임은 실제 시간/득점/AI/공동순위 규칙을 사용한다. 연습 안내는 준비 버튼을 누르기 전 자동 시작하지 않는다.

연습 종료·로비 복귀·새 모험은 세션을 초기화한다. 연습 건설, 재료, 미니게임 완료 목록, 보상은 새 모험에 이어지지 않는다. 플레이 기록이나 점수 이력 저장 기능은 추가하지 않았다.

### 모든 미니게임의 조작 연습

9개 미니게임 모두 시작 안내에서 **조작 연습(P)** 을 선택할 수 있다. 키보드 Tab으로 버튼을 선택한 뒤 Enter로도 시작한다. 아래 단계는 실제 게임의 성공 이벤트에 따라 진행하며, 가만히 기다리는 것으로 완료되지 않는다.

| 게임 | 직접 해보는 행동 |
| --- | --- |
| 태양광 | 햇빛을 정면으로 받는 패널 경로를 두 번 선택 |
| 풍력 | 풍향 정렬로 발전 → 위험 돌풍에서 새로 브레이크 |
| 스마트그리드 | 실제 공급 조절 후 1초 균형을 유지하고 수요 변화에 다시 대응 |
| 대기전력 | 사용하지 않는 기기의 대기전력 두 번 차단 |
| 수력 | 레버로 이동 → 세 번 눌러 열기 → 실제 발전 → 닫아 물 모으기 |
| 에너지원 분류 | 두 개 분류, 틀린 선택을 바로잡아도 연습 단계 인정 |
| 배터리 | 태양광의 남는 전기를 배터리에 저장 → 흐릴 때 도시로 공급 |
| 통학버스 | 실제 정류장에서 2명 이상 태우기 → 학교에 정확히 정차 → 입장 애니메이션 |
| 여름철 창문 | 열린 창문을 두 번 닫아 냉방 전기 사용 속도 변화 확인 |

수력은 30초, 나머지 연습은 최대 60초다. 완료하면 성공 안내 후 시작 안내로 돌아오며, Esc로도 돌아갈 수 있다. 연습 점수·목표·준비 상태는 본게임에 반영되지 않는다. 원래 라운드 시드로 모든 게임 상태를 초기화하고 시작한다. 오프라인에서는 연습하는 동안 준비 자동 시작을 기다려 준다. 온라인에서는 호스트의 동시 시작 시각을 유지하며, 시작 전 연습 상태를 초기화한다.

`AllMiniGamePracticeTest`는 아홉 게임의 실제 행동 결과, 잘못된 분류 후 수정, 점수·보상 분리, 같은 시드 복원, 호스트 시작 중 연습 종료와 온라인 준비 제한시간을 검증한다. `StandaloneBrowserSmoke.cjs --practice`는 아홉 웹 링크에서 실제 키 입력으로 연습 진입·이동·복귀·본게임 시작을 확인한다.

## 검증

- CI에 튜토리얼·화면 회귀와 함께 `AllMiniGamePracticeTest`, `EndingPresentationTest`, `RenderQualityTest` 추가.
- 실제 키 이벤트로 캐릭터 선택창 Tab 순환, 주사위, 도감 목표 선택, 퀴즈, 키보드 건설 및 정상 모험 초기화를 검증.
- 별도 실제 키 입력 시뮬레이션으로 30초 미니게임과 결과 대기를 포함한 전체 튜토리얼 완료, Esc 취소와 이전 세션 콜백 차단 확인.
- 기존 규칙·퀴즈·공동 건설·미니게임 공정성·버스 마감 애니메이션·네트워크 회귀와 전체 AI 시뮬레이션을 포함한 32개 검사에서 성공 확인.
- 실제 두 프로세스 온라인 동시 진행·점수 일치와 AI 전체 게임의 4인 최종 결과 시뮬레이션 통과.
- 1280×720, 1024×600 실제 렌더 확인. Web 검사용 `TutorialBrowserSmoke.cjs`는 실제 마우스/키 입력의 단계별 화면을 남겨 육안 확인한다.

실제 교실 기기에서의 프레임 속도와 학생이 처음 접했을 때의 이해도·재미는 별도 현장 관찰이 필요하다. 이번 검증은 기능 및 화면 검증이며 학생 사용자 테스트를 대체하지 않는다.
