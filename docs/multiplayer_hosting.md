# 플레이어 호스트 멀티플레이 사용법

이 게임은 별도의 게임 서버를 운영하지 않는다. 방을 만든 플레이어의 게임이 권한 서버 역할을 하며, 참가자는 방장이 만든 6자리 숫자 코드로 접속한다. IP 주소와 포트는 게임이 자동으로 찾는다.

## 플레이 방법

1. 방장은 로비에서 `온라인 모험`을 선택하고 `방 만들기`를 누른다.
2. 화면에 자동 생성된 6자리 방 코드를 다른 플레이어에게 알려 준다.
3. 참가자는 `온라인 모험`을 선택하고 `6자리 방 코드`를 입력한 뒤 `방 참가`를 누른다.
4. 방장 화면의 참가자 목록을 확인하고 `게임 시작`을 누른다.
5. 최대 4명까지 참가할 수 있으며 빈 자리는 시작할 때 AI가 채운다.

## 다른 네트워크 연결

`network/room_directory_url`에 배포한 Cloudflare Worker 주소가 설정되어 있으면 방장은 UPnP로 UDP `8910` 포트를 자동 개방하고, 6자리 코드와 접속 주소를 방 코드 서버에 임시 등록한다. 참가자는 다른 Wi-Fi나 모바일 네트워크에서도 같은 코드로 접속할 수 있다. 실제 게임 데이터는 Cloudflare를 거치지 않고 플레이어끼리 직접 주고받는다.

연결 서버가 설정되지 않았거나 UPnP 준비가 실패하면 기존 LAN 검색으로 자동 전환된다. 이 경우 모든 플레이어가 같은 공유기·학교 네트워크에 있어야 하며, Windows 방화벽에서 게임의 사설 네트워크 통신을 허용해야 한다. 게임 연결은 UDP `8910`, LAN 방 코드 검색은 UDP `8911`을 사용한다.

일부 통신사의 CGNAT 환경은 공유기에서 포트를 열어도 외부 직접 접속이 불가능하다. 이 환경까지 지원하려면 별도의 게임 패킷 릴레이가 필요하다.

방 코드 서버의 배포 방법은 [`services/room-directory/README.md`](../services/room-directory/README.md)를 따른다.

## 동기화 원칙

- 방장이 게임 시간, 턴, AI, 주사위 결과, 퀴즈 판정과 건설 결과를 최종 결정한다.
- 참가자는 자기 캐릭터의 주사위, 퀴즈, 특수기술, 완주 보상과 개인 재료 건설만 요청할 수 있다.
- 캐릭터 위치, 개인 재료, 획득 완료 타일, 사다리·미끄럼틀, 공동 마을과 엔딩은 모든 화면에 동일하게 동기화된다.
- 참가자가 나가면 방장 게임에서 해당 캐릭터를 AI가 이어서 플레이한다. 방장이 나가면 참가자는 로비로 돌아간다.
