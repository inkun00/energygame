# 게임 화면 문구 점검

점검일: 2026-11-05

## 기준

화면 문구가 다음 중 하나를 돕는지 확인했다.

- 지금 해야 할 행동, 조작키, 시간, 점수, 보상, 실패 조건
- 요정마을의 상황과 캐릭터의 역할
- 플레이한 행동과 에너지 변화의 관계
- 접속·복구·접근성 안내와 에셋 출처

그 외 반복되는 표어, 구현 방식 설명, 과장된 수식어를 삭제하거나 줄였다. 코드 주석과 개발 문서의 기술 용어는 플레이어에게 노출되지 않으므로 삭제 대상에 포함하지 않았다.

## 수정한 화면

| 화면 | 수정 |
| --- | --- |
| 로딩 | 제목을 반복하는 영어 문구와 표어 삭제. 진행 상태는 ‘게임을 불러오는 중’으로 표시. 미니게임을 모두 30초로 안내하던 문구 삭제. 기존 생성 이미지는 그대로 유지. |
| 로비·오프닝 | ‘복원 프로젝트’ 반복 푸터 숨김. ‘밸런스형·기동형·연금술형’ 소개 대신 캐릭터의 역할을 짧게 표시. 이야기의 원인과 목표는 유지하고 문장을 줄임. 탐험 시간 안내에 새 마을 계획·전기 시험 반영. |
| 보드 칸 설명 | 막연한 ‘친환경 전략 기회’를 실제 보상인 ‘건설 부품 1개’로 표시. 어려운 ‘포텐셜에너지’, 힘과 에너지를 혼동한 설명, 햇빛이 무한하다는 표현을 수정. 수소 설명의 배출 제로 단정과 ‘수도꼭’ 오타를 수정. |
| 미니게임 목록 | ‘체험·아케이드’ 장식 대신 ‘4인 동시 도전’과 실제 조작 연습 방법을 표시. |
| 미니게임 안내·결과 | ‘양수 점수’를 ‘1점 이상’으로 변경. 결과 버튼과 중복되던 재플레이 설명 삭제. 연습 완료 안내와 제목을 줄이고 관련 없는 일반 과학·콤보 안내 기본값 삭제. 숨겨진 기존 안내 문자열도 같은 기준으로 정리. |
| 태양광 게임 | 충돌에 대한 ‘충격량만큼’, 점프에 대한 ‘발전 경로를 지켰어요’ 표현을 실제 보이는 행동으로 수정. 직접 길을 골라야 득점한다는 조건은 유지. |
| 냉방 게임 | ‘에어컨 사용 속도가 느려져요’를 ‘에어컨이 쓰는 전기가 줄어요’로 수정. |
| 수력 게임 | kWh로 표시하는 누적 에너지를 ‘생산 전력’ 대신 ‘만든 전기’로 표시. |
| 엔딩 | 고정 친환경 지수 대신 실제 낮·밤 전기 공급률 표시. 건설 내용과 무관한 ‘태양·바람·물’ 일괄 설명, 주민을 구조했다는 플레이 밖의 이야기를 삭제. 성공·부족 결과와 저장·발전·절전의 관계를 짧게 설명. |

## 유지한 내용

- 각 게임의 조작키, 위험 경고, 득점 조건, 보너스 달성 조건
- 순위 보너스 20 / 10 / 5 / 1과 공동 순위 규칙
- 실제 행동·측정값에 따른 학습 피드백과 게임 속 비교값 표시
- AI 동료 표시, 연결 실패·대기 안내
- 오프닝의 세계관, 캐릭터 이름, 에셋 출처·라이선스
- 저장하지 않는 한 판의 결과 화면. 플레이 기록 저장 기능은 추가하지 않음.

## 연동 확인

- `EndingCinematic.setup`은 기존 네 인자를 유지하며 마지막 선택 인자로 전기 시험 요약을 받는다.
- `daytime_coverage`, `night_coverage`는 0~1 비율을 화면에서 백분율로 표시한다. 요약을 복사하여 이후 상태 변경의 영향을 받지 않는다.
- 원자력을 포함할 수 있는 마을 전체를 ‘재생에너지’ 발전소라고 부르지 않는다.
- HUD·퀴즈·튜토리얼·공동 계획 문구는 해당 화면의 기능 개편과 함께 정리한다.

## 검증

- 로딩 화면의 기존 WebP 이미지 데이터가 변경되지 않았음을 SHA-256으로 확인했다.
- `EndingPresentationTest`는 낮·밤의 실제 공급률, 결과 요약의 복사, 기존 패널 배치와 입력 동작을 검증하도록 갱신했다.
- 기능 통합 후 `EndingPresentationTest`, `MiniGameVisualStyleTest` 통과. 엔딩은 1280×720·1024×600 배치와 입력, 미니게임은 9종의 기존 장면·에셋 사용을 확인했다.
- `MiniGameLearningFeedbackTest`, `BoardReadabilityTest` 통과. 9종 학습 결과·실시간 안내와 보드 100칸의 표시·읽기 순서를 확인했다.
- 로딩 HTML의 인라인 JavaScript 구문 검사 통과.
- 추가 회귀 검증: 배포 워크플로에서 담당 범위의 Godot 테스트 25개와 방 서버 테스트 14개 통과. 종료코드뿐 아니라 `SCRIPT ERROR`, `Parse Error`, `[FAIL]`, `ERROR:` 로그도 확인했다.
- 기존 문구를 그대로 요구하던 검사 2개는 새 의미에 맞게 갱신했다. 탐험 시간 안내는 미니게임·건설·전기 시험 제외 여부를 확인하고, 퀴즈 결과는 에너지·SP·부품 보상 표시와 실제 SP 지급·부품 선택 생성을 확인한다.
- 상세 검증 로그: `.godot/qa-copy-regression-20261105/`. 최초 실패 로그와 수정 후 로그를 따로 보관했다.
